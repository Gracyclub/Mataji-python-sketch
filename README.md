# 🔱 Maa Durga Live Sketch Animation using Python Turtle

A Python-based creative coding project that brings the divine silhouette art of **Maa Durga on Lion** to life. Using **Python Turtle** and **OpenCV**, it traces real reference contours layer-by-layer with live cursor movements.

---

## ✨ Features
- **Live Cursor Sketching:** Dynamic turtle cursor draws the silhouette right in front of your eyes.
- **Hierarchical Contour Tracing:** Uses OpenCV's `RETR_TREE` to capture intricate inner cuts (Lion's face, eyes, mane, Maa Durga's weapons, hands, and ornaments).
- **Dual-Layer Shading:** Seamlessly alternates black silhouettes and white cutouts for 100% exact reference matching.

---

## 🚀 Quick Setup & Run

Run the following commands in your terminal to set up and run the project:



# Clone the repository
```
git clone [https://github.com/Gracyclub/Mataji-python-sketch.git](https://github.com/Gracyclub/Mataji-python-sketch.git)
```

# Enter project directory
```
cd Mataji-python-sketch
```
# Install required packages
```
pip install opencv-python numpy
```
# Run the python script (Make sure mataji.jpg is inside the folder)
```
python mataji.py
```
